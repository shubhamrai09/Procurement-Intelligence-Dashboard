<h2 align="center">🚀 Project Overview</h2>

<p align="center">
  An interactive procurement analytics dashboard designed to explore
  purchase transactions, analyze vendor performance, compare material
  prices, and identify potential sourcing opportunities across financial years.
</p>

<h2>✨ Key Features</h2>

- 📊 Procurement Overview & KPI Analysis
- 🏢 Vendor Performance Analysis
- 📅 Year-wise Vendor Purchase Analysis
- 🔄 Vendor Status Analysis
- 📦 Item Group Analysis
- 🔍 Material / Item Analysis
- 💰 Vendor Price Comparison
- 💡 Procurement Opportunities
- 📋 Transaction-Level Data Exploration
- 🔎 Search, Sorting & Pagination
- 📤 Filtered Transaction CSV Export

<h2>🛠️ Technologies Used</h2>

<p>
  <strong>HTML5</strong> 🌐 &nbsp;&nbsp;
  <strong>CSS3</strong> 🎨 &nbsp;&nbsp;
  <strong>JavaScript</strong> ⚡ &nbsp;&nbsp;
  <strong>Chart.js</strong> 📊
</p>

<h2>📈 Business Objectives</h2>

- Analyze historical purchasing trends.
- Understand vendor contribution and supplier concentration.
- Compare recorded prices for the same material across vendors.
- Identify single-source materials for further investigation.
- Explore potential procurement and sourcing opportunities.
- Export transaction data for additional analysis.
